Research projects

Shared memory for data agents

MAVRA · PostgreSQL and Rust

I built MAVRA to let data agents share versioned definitions of metrics and features in PostgreSQL. The prototype tracks whether each definition remains valid after a data update and checks which revision a query uses.

MAVRA source code

Transaction routing in multi-writer databases

KingbaseRAC · January–June 2025

In a collaboration between RUC’s database systems group and Kingbase, I implemented a workload-aware router in C++. The router uses METIS to partition a graph of transactions and the data they access. It directs transactions with overlapping access patterns to the same node to limit cross-node communication.

Query execution, indexing, and recovery

RushDB · 2024–2025

My RushDB teammates and I implemented B+ tree indexes, concurrency control, and log-based recovery in RucBase. For the OceanBase Database Competition, we extended MiniOB to handle nested and correlated subqueries and optimized vector search in OceanBase.
