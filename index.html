Research & systems

Semantic memory and validation for data agents

MAVRA · PostgreSQL & Rust · 2026–Present

A Rust and PostgreSQL prototype for sharing versioned metric and feature definitions across data agents. MAVRA tracks whether registered definitions remain semantically valid after underlying data updates and verifies which revision a query executes against.

MAVRA source code (agent4db-adapter)

Workload-aware transaction routing in multi-writer databases

KingbaseRAC · RUC & Kingbase Collaboration · 2025

Implemented a workload-aware transaction router in C++ for multi-writer clusters in a collaboration between RUC’s database systems group and Kingbase. The router partitions a graph of transactions and their accessed data using METIS, directing overlapping access patterns to the same node to minimize cross-node communication.

Relational query execution, indexing, and vector search

RushDB · OceanBase & RucBase · 2024–2025

Led the RushDB team in national database system competitions. Implemented B+ tree indexes, two-phase locking, and write-ahead logging recovery with checkpoints in RucBase, and extended MiniOB with nested and correlated subqueries alongside vector search optimizations in OceanBase’s VSAG library.
