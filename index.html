MAVRA / PostgreSQL · Rust

数据智能体的共享记忆

同一个指标被多个智能体使用时，怎样知道它们采用的是哪一版定义？我在 PostgreSQL 上构建原型，保存经过检查的指标定义和特征，在数据更新后检查它们是否仍然有效，并在执行时核对版本。

项目代码

KingbaseRAC / 2025.01–06

多写数据库的事务路由

在中国人民大学数据库系统研究组与金仓的合作项目中，我用 C++ 实现了负载感知的路由模块。它根据数据与事务的访问关系做图分区，将相关请求发往同一节点，以减少跨节点通信。

RushDB / 2024–2025

从关系查询到向量检索

我和 RushDB 队友为 RucBase 实现了 B+ 树索引、并发控制和日志恢复。参加 OceanBase 数据库大赛时，我们为 MiniOB 补全嵌套与关联子查询，并在决赛中优化了 OceanBase 的向量检索。
