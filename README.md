# Ming Tai

[Academic homepage](https://mmmttt000045.github.io/) of Ming Tai, a Ph.D. student at Renmin University of China (2026–Present).

The site is served by GitHub Pages from the root of the `main` branch. Pushing changes to that branch publishes the site.

| Content | File |
| --- | --- |
| Profile, contact information, research, education, and honors | `index.html` |
| Page styles | `assets/site.css` |
| English curriculum vitae | `assets/Ming-Tai-CV.pdf` |

The university emblem comes from [Renmin University of China](https://en.ruc.edu.cn/att/26.files/images/share_logo.png). The GitHub profile link uses the black Invertocat from the [GitHub Brand Toolkit](https://brand.github.com/foundations/logo).

The CV link opens the PDF in a new tab. The profile links to [Prof. Wei Lu](https://deke.ruc.edu.cn/kytd/zzry/96cb94af916145319b459be6c94acd2c.htm) and the [Key Laboratory of Data Engineering and Knowledge Engineering (MOE)](https://deke.ruc.edu.cn/).

The previous English address at `/en/` redirects to the homepage. To preview changes locally, run `python -m http.server 8000 --bind 127.0.0.1` in the repository root and open the [local site](http://127.0.0.1:8000/).
