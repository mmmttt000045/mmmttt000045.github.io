01PROJECTS

Research projects

MAVRA / PostgreSQL · Rust

Shared memory for data agents

When several agents use the same metric, how can they tell which definition they used? I built a PostgreSQL-backed prototype that stores checked metric definitions and features, tracks their validity as data changes, and checks revisions at execution time.

Source code

KingbaseRAC / Jan–Jun 2025

Routing transactions in a multi-writer database

In a project between RUC’s database systems group and Kingbase, I implemented a workload-aware router in C++. It partitions a graph of transactions and the data they access, then routes related requests to the same node to reduce cross-node communication.

RushDB / 2024–2025

From relational queries to vector search

My RushDB teammates and I implemented B+ tree indexes, concurrency control, and log recovery in RucBase. In the OceanBase competition, we added support for nested and correlated subqueries to MiniOB and optimized vector search in OceanBase for the final round.
